# Сюжетный мод — устройство

Рабочий документ чата «Сюжет»: из чего состоит мод и в каком порядке его делать. Тексты — в «Сюжет: ветки, голос и тексты». Дата: 27 октября 2026. Статус: прикидка.

## Рамки

- Только одиночная игра, мультиплеера нет. Состояние сюжета одно на мир, катсцены показываются единственному игроку.
- Язык — русский. Английский возможен позже, не приоритет: ключи текстов сразу заводятся так, чтобы перевод был простым.
- Мод сюжета зависит от «Ядра» и работает только через его события и точки управления.

## Состав

### 1\. Каркас и состояние

- Ветка: параметр в конфиге мода (по умолчанию public, комментарий «ветка для стрима автора»). При первом запуске мира записывается во флаг мира в ядре, дальше конфиг на этот мир не влияет.
- Состояние сюжета в данных мира: полученные записи, показанные катсцены, «первые разы», ступени чертежа, исход финала.
- Отладочные команды /сюжет: вызвать событие, повторить катсцену, сбросить журнал, показать флаги и ветку.

### 2\. Журнал героя

- Экран по клавише и кнопке в инвентаре. Записи в хронологии, игровой день, отметка новых.
- Страницы: записи, чертёж врат (5 ячеек × 3 ступени, имя опоры после встречи), условия торговца.
- Всплывающее сообщение на вехе дублируется записью в журнал.
- Внешний вид журнала — открытый вопрос.

### 3\. Записи на данных

- Каждая запись описана JSON-файлом: событие, условия, ветка, режим (один раз / случайно из набора уровня).
- Тексты в lang-файлах, ключ с суффиксом ветки (.public / .streamer); нет стримерского варианта — берётся общий.

### 4\. Субтитры и реплики

- Нижняя строка с именем говорящего: катсцены, торговец, жители, герои.
- Система реплик: событие → набор строк, радиус, откат, частота по рангу героя (ученики чаще, мастера реже).

### 5\. Катсцены

- Свой движок: камера по ключевым кадрам, блокировка ввода, пропуск удержанием клавиши. Таймлайн в JSON: сущности, анимации, частицы Хаоса из ядра, субтитры.
- 7 сцен: вступление (2 варианта), первый ритуал (без камеры), 5 появлений опор, финал. Ядро на время сцены ставит механики на паузу.
- Вступление: постройка из NBT-шаблона в измерении-сцене ядра, после сцены игрок у точки появления.
- Модель игрока со скином и анимацией вставания из приседа — нужна библиотека анимации тела игрока (проверить наличие под 1.21.1 NeoForge).

### 6\. Торговец, опоры, финал

- Торговец: реплики при ритуале (приветствия, вехи, открытие счёта, особые продажи, передачи от владыки в стримерской ветке), условия в журнал.
- Опоры: катсцена при первой встрече с видом, запись после первой победы, отметка ячейки чертежа при подборе материала, запись «все пять собраны».
- Финал: катсцена, исходы А и Б, эпилог по ветке, затем свободная игра.

### Триггеры, которые мод закрывает сам

Ванильные события: первая ночь (сон или рассвет), первый золотой слиток, первая смерть, первый вход на базу (смена измерения), вход в выжженные земли и Предел (по тегу биома), подбор материалов опор.

## Формат записей журнала

- Одна запись — один JSON-файл в data/\<мод\>/journal/\<раздел\>/\<имя\>.json, id записи — путь файла. Тексты лежат в assets/\<мод\>/lang/ru\_ru.json.
- Поля: trigger (type и параметры), text (ветка → список ключей), page (entries, trader или epilogue, по умолчанию entries), repeat (once или pool, по умолчанию once), popup (всплывающее сообщение).
- text: ключи public и streamer или common для обеих веток. В режиме once ключи — абзацы одной записи, в режиме pool — варианты, из которых берётся один.
- pool без повторов: вариант берётся случайно из неиспользованных; когда набор исчерпан, запись на это событие больше не добавляется.
- first у node\_absorbed: game — первое за игру, level — первое на уровне, none — повторные. На одно поглощение срабатывает одна запись; на уровне 1 первым считается первое за игру.
- Реплики торговца на вехах лежат в ключах story.trader.\*, они общие для субтитров и страницы «Торговец».
- Заглушки: id мода story, ядра core, теги биомов story:scorched\_lands и story:predel, измерение core:base. Заменяются при старте кода.
- Разложено 42 записи, 100 строк, около 1500 слов. Не входят: чертёж врат (написана только суть, местность и носитель нет), обычные реплики торговца, жители и герои — у них свой формат.

## Порядок работы

1. Каркас: ветка, состояние, команды, журнал, записи по ванильным триггерам. Готово в срезе 1 (PR \#10), вместе с событиями ядра среза; страница чертежа врат — позже.
2. Субтитры, система реплик, торговец. Субтитры и торговец готовы (PR \#10); реплики жителей и героев — вместе с их событиями ядра.
3. Движок катсцен и вступление.
4. Опоры и финал (больше всего зависят от ядра и моделей).
