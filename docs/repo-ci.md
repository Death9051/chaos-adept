# Репозиторий и CI

Дата: 27 октября 2026. Статус: каркас в репозитории github.com/Death9051/chaos-adept, первый прогон CI зелёный (build, servertest, clienttest).

## Репозиторий

- Один репозиторий на оба мода, публичный, на GitHub. Имя: chaos-adept.
- Gradle с двумя подпроектами: core («Ядро», adept\_core) и story («Сюжет», adept\_story). Сюжет зависит от ядра той же версии, версия одна на оба мода.
- Платформа: Minecraft 1.21.1, NeoForge 21.1.264, ModDevGradle 2.0.148, Gradle 9.2.1, Java 21. Версии сверены с официальным MDK NeoForge 1.21.1.
- Пакет кода: ru.adept. Публичное API ядра: ru.adept.core.api.
- Почему публичный: минуты GitHub Actions бесплатны и без лимита, оплатить приватный тариф из России сложно. Цель стримерской ветки — не включить её случайно, а не скрыть, поэтому открытые тексты не мешают.

## Что уже в каркасе

- Флаги мира в ядре (WorldFlags): хранилище «ключ → строка» в сохранении, туда пишут другие моды.
- Конфиг сюжета config/adept\_story-common.toml, параметр branch (PUBLIC по умолчанию, STREAMER), без экрана настроек. Ветка записывается в мир при первом запуске.
- Зависимость сюжета от Player Animation Library; анимации в assets/adept\_story/player\_animations.

## CI (GitHub Actions)

- build: сборка обоих модов, jar в артефактах.
- servertest: сервер прогоняет геймтесты обоих модов (runGameTestServer).
- clienttest: клиент под виртуальным экраном создаёт мир, проводит в нём 200 тиков и выходит; тест пройден, если в логе есть маркер ADEPT\_CLIENTTEST\_OK. Автотест включается только системным свойством, в игре его нет.
- logs: логи каждого прогона в ветке ci-logs (runs/номер-коммит, итог в result.txt, последние 30 прогонов). Их можно читать по прямой ссылке, без входа.
- fullpack: прогон с полным модпаком, добавляется вместе со сборкой модпака.
