# Вопросы между чатами

Общий документ для передачи вопросов между чатами проекта. Каждый чат дописывает вопросы в раздел адресата, а адресат отмечает решение и переносит его в свой черновик. Формат пункта: вопрос, от какого чата, дата, статус (открыт / решён: ссылка на документ).
