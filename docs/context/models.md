# Контекст проекта: Модели и анимации

## Что это

Создание моделей, текстур и анимаций для второй сборки Minecraft. Модели делаются в Blockbench, анимации — для GeckoLib. Готовые файлы передаются в проект «Ядро» для подключения.

## Инструменты

- Blockbench на компьютере пользователя с MCP-плагином: Claude напрямую строит модели и анимации и снимает скриншоты окна для проверки. Кандидат — плагин jasonjgardner (blockbench-mcp-plugin); есть вариант MCP-сервера с поддержкой моделей и анимаций GeckoLib.
- Для работы чат должен быть связан с компьютером через десктопное приложение Claude, Blockbench открыт.
- Целевая платформа: Minecraft 1.21.1, NeoForge, GeckoLib.
- Подгонка в самой игре — по скриншотам и коротким видео пользователя.

## Опорные документы (папка «Майнкрафт — вторая сборка» на Google Диске)

- «Свод решений — черновик 1» — артефакты, стадии, транспорт, станции.
- «Опоры, защитники и моды — черновик 1» — облик и атаки опор.

## Что входит

- Артефакты по стадиям внешнего вида. Технические: ранняя версия «на коленке» с рунами-заплатками и кристаллами, поздняя — чистая техника с аккуратными магическими вставками. Магические — зеркально.
- Пары артефактов: гаусс / рельса, клинок / молот, лёгкий экзокостюм / тяжёлая силовая броня, бур / шахтёрский лазер, шагоход / скиммер.
- Котёл душ, накопитель, ключ, резонатор, хранилище, лагерь в развёрнутом виде.
- Опоры (боссы) со всеми атаками: Корневой хранитель, Каменный колосс, Хозяйка миражей, Сердце вулкана, Живая жила; позже финальный защитник.
- Свои мини-боссы, если решим.
- Станции базы.
- Анимации: стрельба, перезарядка, удары, развёртывание лагеря и транспорта, атаки и фазы боссов.

## Стиль

- Общий стиль сборки техно-магический.
- Опоры — стилистически и логически под свой биом (Terralith), с уникальными атаками.

## Что не входит

- Логика поведения и подключение в код — проект «Ядро».

## Как работаем

- Всё на русском.
- Сначала заготовка формы и пропорций, согласование, потом детали, текстура, анимации.
- После согласования направления детали дизайна можно придумывать самостоятельно.

## Открытые вопросы этого проекта

- Выбор и настройка MCP-плагина Blockbench.
- Общий визуальный язык техно-магии: палитра, свечение, материалы.
- Порядок работы: с чего начинаем (вероятно, первый артефакт или первая опора как эталон качества).
