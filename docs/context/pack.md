# Контекст проекта: Сборка

## Что это

Сам модпак второй сборки Minecraft: подбор и настройка сторонних модов, интеграция с нашими модами («Ядро» и «Сюжет»), CI и тесты, публикация в открытый доступ.

## Платформа

- Minecraft 1.21.1, NeoForge, Java 21.

## Опорные документы (подпапка «Черновики» в папке «Майнкрафт — вторая сборка»)

- «Список модов — черновик 1» — согласованный состав модов, главный документ этого чата.
- «Мобы — черновик 1» и «Опоры, защитники и моды — черновик 1» — какие мобы из модов где используются, что выключить.
- «Свод решений — черновик 2» и «Сюжет, темп и вехи — черновик 1» — для понимания, что сборке нужно.
- «Вопросы между чатами» (корень папки) — раздел «Для „Сборки“».

## Принятые решения

- Состав модов согласован в «Списке модов»: генерация Tectonic + Terralith + YUNG's + AdoraBuild: Structures; мобы Naturalist, Mowzie's Mobs, Bosses of Mass Destruction, Born in Chaos, Improved Mobs; удобства и оптимизация там же.
- Сторонние моды — только генерация мира, мобы, библиотеки (GeckoLib), удобства и оптимизация. Артефакты и транспорт полностью свои.
- Средняя по размеру сборка, 30–50 часов; генерация умеренная, чтобы игрок увидел большую часть контента модов.
- Обычные защитники — мобы из модов, «одержимая фауна» биома. Сложность Improved Mobs растёт с уровнем узлов, ядро поднимает её командой.
- Лут и снаряжение модов с боссами вычищаем или заменяем нашими материалами.
- Только одиночная игра. Сборка выходит одной полной версией, без поэтапных релизов.

## Что входит

- Репозиторий на GitHub и каркас кода: моды «Ядро» и «Сюжет» на NeoForge 1.21.1, сюжет зависит от ядра.
- Итоговый список модов, проверка версий и совместимости.
- Конфиги: генерация, спавн мобов, лут-таблицы.
- Сверка идентификаторов биомов Terralith (выгрузкой из игры) для привязки логов опор.
- CI: сборка, серверный автотест, клиентский тест. Опыт «Осколка Хаоса»: схема build / servertest / clienttest / fullpack, артефакты логов в отдельной ветке. Учесть, что минуты GitHub Actions на приватном репозитории могут упираться в лимит оплаты.
- Оптимизация производительности.
- Публикация: страница сборки, описание, версии.

## Что не входит

- Код механик — «Ядро». Сюжет — «Сюжет». Модели — «Модели и анимации».

## Как работаем

- Всё на русском.
- Пользователь живёт в России: учитывать доступность сервисов и площадок.

## Открытые вопросы этого проекта

- Устройство репозитория: один на оба мода или два; публичный или приватный (на публичном GitHub Actions бесплатны).
- Точные версии и зависимости; перенос логов Bosses of Mass Destruction в наши биомы.
- Библиотека анимации тела игрока под 1.21.1 NeoForge для вступительной катсцены.
- Площадка публикации (CurseForge, Modrinth) с учётом доступности из России.
- Решено: состав модов («Список модов»), пак структур AdoraBuild, одна полная версия без поэтапных релизов.
- Название сборки.
