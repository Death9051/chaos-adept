# Материалы и расходники

Дополнение к «Своду решений». Дата: 22 октября 2026. Статус: концепт. Здесь расходники и материалы: прочность фокусов, ячейки, руны, снаряды, пластины, новые руды, сплавы, фокусы и сплавы кристаллов. Артефакты — в «Артефактах», машины — в «Базе и машинах».

## Прочность фокусов

Общее правило для всех фокусов. Каждое срабатывание изнашивает фокус: у энергоклинка каждое попадание, у молота каждый заряженный удар, у брони каждое срабатывание эффекта фокуса. Когда прочность кончается, фокус с некоторым шансом трескается (гаснет, его можно починить) или ломается (пропадает). Изношенный фокус можно чинить и до нуля. Машина для починки определяется вместе с производством. Износ виден по самому кристаллу: он темнеет и покрывается трещинами.

## Переносные ячейки

- Одноразовые: ячейка разрушается, как только опустеет. Заряжает их зарядник.
- Материал — ванильные камни (лазурит, редстоун, аметист, алмаз, изумруд, кварц), огненный опал, астралит и сплавы кристаллов; кристаллы с узла остаются топливом генератора.

#### Способ изготовления

- Огранённый природный камень (ограночная машина): быстрая отдача, малая ёмкость.
- Выращенный кристалл без огранки (выращиватель, из расплава камня): большая ёмкость, медленная отдача.
- Выращенный и огранённый кристалл (выращиватель → ограночная машина): большая ёмкость и быстрая отдача.

#### Материал

- Бонусы материалов касаются только передачи заряда, артефакты они не усиливают.
- Лазурит: мана; дешёвый; отдаёт весь заряд мгновенно.
- Редстоун: электричество; дешёвый; отдаёт весь заряд мгновенно; бывает только выращенным.
- Аметист: мана; сам понемногу восстанавливает заряд, пока не опустел.
- Алмаз: мана и электричество одновременно; удобен для гибридного ближнего боя.
- Изумруд: ресурс выбирается при зарядке; отдаёт заряд постепенно, долгой подпиткой.
- Огненный опал: мана; «Перезаряд» — отдаёт заряд сверх полного, артефакт получает запас примерно на четверть выше максимума, излишек постепенно сгорает.
- Астралит: электричество; «Раздача» — отдаёт заряд сразу всем артефактам поровну.
- Кварц: электричество; «Пьезо» — удары по игроку понемногу подзаряжают ячейку, пока она не опустела.

## Руны

- Руны только на расходниках (иглы, снаряды, пластины). Простые эффекты (урон, пробой, огонь, холод, отбрасывание) — это зачарования «Рассеянного луча», не руны.
- Руна — буква: у каждой две роли. Основа — её эффект, если руна стоит первой. Грань — как она меняет основу, если стоит второй или третьей. Слово = основа + грани, порядок важен (8 рун: 56 пар и 336 троек).
- Особые слова: при точном порядке рун системный результат заменяется уникальным эффектом. Каждое особое слово полностью самостоятельно, ни от каких внешних эффектов не зависит.
- Гравировка изделия делается одним материалом (металл или минерал). Материал задаёт множитель эффекта, шанс не стереться и модификатор для всех рун изделия.
- Шанс стирания бросается один раз на всю гравировку (при подборе снаряда). Если стёрлась — пропадает всё: слово и эффекты букв. Встроенные руны (выращиватель) не стираются никогда.
- Кристалл, добавленный в сплав через «Резонанс» сплавщика, повышает множитель.

#### Материалы гравировки (ориентировочно)

- Медь: ×0,8; не стирается 40%; «Цепь» — эффект с шансом перекидывается на ближайшую цель.
- Железо: ×1,0; 50%; без модификатора.
- Сталь (железо + уголь): ×1,1; 75%; без модификатора.
- Золото: ×1,2; 30%; «Отклик» — каждое срабатывание возвращает немного маны.
- Красное золото (золото + медь): ×1,3; 50%; «Созвучие» — одинаковые руны на изделии усиливают друг друга сильнее обычного.
- Незерит: ×1,5; 90%; «Неугасимость» — длительные эффекты держатся дольше.
- Алмаз: ×1,4; 85%; «Ясность» — зоны рун (трещины, облака, поля) больше и держатся дольше.
- Изумруд: ×1,1; 60%; «Удача» — шанс, что слово сработает дважды.
- Лазурит: ×0,9; 40%; «Экономия» — гравировка тратит вдвое меньше материала.
- Редстоун: ×0,9; 40%; «Мгновенность» — эффекты рун срабатывают без задержек.

#### Руны: основа / грань

- Ток: разряд перескакивает на две цели / эффект цепью перекидывается на соседей.
- Пламя: поджог, огонь переходит на соседей при смерти цели / эффект оставляет горящую зону.
- Узы: связь двух врагов, урон дублируется / эффект делится на связанные цели.
- Эхо: удар повторяется через секунду / эффект срабатывает повторно.
- Разлом: трещина с замедлением и уроном по площади / эффект закрепляется в точке как зона.
- Тяга: точка попадания притягивает врагов / перед эффектом враги стягиваются.
- Иней: цель замерзает, разбитая цель ранит соседей / эффект замораживает.
- Пустота: цель на время теряет защиту / эффект игнорирует броню и сопротивления.

#### Особые слова из двух рун

- «Гроза» (Ток + Эхо): над точкой попадания встаёт облако и несколько секунд бьёт молниями по врагам.
- «Извержение» (Пламя + Разлом): в точке попадания открывается жерло и разбрасывает огненные сгустки.
- «Аркан» (Узы + Тяга): цель и два ближайших врага стягиваются в одну точку и оглушаются при столкновении.
- «Двойник» (Эхо + Узы): копия снаряда отскакивает от цели и бьёт всех врагов на линии до препятствия.
- «Ледник» (Иней + Разлом): вокруг точки попадания ледяное поле, враги на нём вмерзают и обездвижены на пару секунд.
- «Чёрная дыра» (Пустота + Тяга): точка затягивает врагов и их снаряды.
- «Сверхпроводник» (Ток + Иней): разряд без затухания обходит всех врагов в радиусе и каждого на мгновение замораживает.
- «Пепел» (Пламя + Пустота): цель горит, и каждая секунда горения ослабляет её следующий удар по игроку.
- «Провал» (Разлом + Тяга): в точке попадания яма выбрасывает врагов вверх, они получают урон от падения.
- «Осколки» (Иней + Эхо): цель покрывается льдом и через секунду взрывается ледяной шрапнелью.

#### Особые слова из трёх рун

- «Сверхновая» (Тяга + Пламя + Разлом): враги стягиваются в горящую трещину, она взрывается.
- «Цепная буря» (Ток + Узы + Эхо): враги в радиусе связываются, по связям раз в секунду бегут разряды.
- «Горизонт событий» (Пустота + Тяга + Эхо): точка несколько секунд затягивает врагов и снаряды, затем схлопывается ударной волной.
- «Хрустальная гроза» (Иней + Ток + Разлом): из трещины растут ледяные кристаллы и бьют разрядами по ближайшим врагам.
- «Жертва» (Узы + Пустота + Эхо): враги в радиусе связываются, самый сильный принимает урон за всех и теряет защиту.
- «Тепловой удар» (Пламя + Иней + Пустота): цель вспыхивает и сразу замерзает, раскалывается и надолго теряет большую часть брони.
- «Тектоника» (Разлом + Узы + Тяга): трещины открываются в точке попадания и под ближайшим врагом, земля между ними проваливается.
- «Плазма» (Ток + Пламя + Тяга): на месте попадания повисает шар плазмы и медленно плывёт к врагам.
- «Вьюга» (Иней + Тяга + Эхо): вокруг точки кружит снежный вихрь, затягивает и замедляет.
- «Распад» (Пустота + Ток + Узы): враги в радиусе связываются и теряют защиту, разряд идёт по связям, каждая смерть в связке взрывается.

## Снаряды и иглы

- Материал задаёт урон, шанс поломки и прямой бонус. Бонус действует на снаряд или цель, не на оружие.
- Литые (литейная): один материал, дешевле и быстрее.
- Выращенные (выращиватель): три слоя, у каждого свой материал. Сердечник задаёт урон, его бонус срабатывает на каждой пробитой цели. Средний слой даёт усиленный бонус. Оболочка задаёт шанс поломки, её бонус срабатывает при разрушении снаряда.
- Медь: урон низкий, поломка высокая; сплющивается — больше урона по целям без брони, меньше по бронированным.
- Железо: урон средний, поломка средняя; лёгкое отбрасывание.
- Золото: урон низкий, поломка высокая; проходит сквозь магические щиты и барьеры.
- Незерит: урон очень высокий, поломка очень низкая; «Раскол» — каждое попадание надолго снижает броню цели, со стаками.
- Аметист (только выращенный): урон средний, поломка высокая; разбивается на осколки и ранит соседей.
- Алмаз: урон высокий, поломка низкая; шанс двойного урона при попадании.
- Изумруд: урон средний, поломка средняя; попадание снимает с цели положительные эффекты.
- Лазурит: урон низкий, поломка высокая; цель на время подсвечивается и видна сквозь стены.
- Редстоун: урон низкий, поломка высокая; попадание прерывает атаку цели.
- Новые руды и сплавы — в разделах «Новые руды» и «Сплавы».

## Пластины тяжёлой брони

- Материал пластины задаёт прочность (сколько урона пластина примет до разрушения) и защитный бонус. Броня отвечает только за выживание: все эффекты пластин защитные или контроль, без урона.
- Руны на пластинах работают в роли «оберега». Слова собираются по тем же правилам: основа — оберег первой руны, грани остальных рун меняют его как на снарядах. Особые слова для брони свои.

#### Материалы пластин

- Медь: прочность низкая; ослабляет урон от электричества и молний.
- Железо: прочность средняя; без бонуса.
- Золото: прочность низкая; ослабляет магический урон.
- Незерит: прочность высокая; не горит, урон от огня и лавы снижен.
- Аметист (только выращенный): прочность средняя; при разрушении пластины игрок на мгновение неуязвим.
- Алмаз: прочность высокая; сильно снижает урон от взрывов.
- Изумруд: прочность средняя; пластина понемногу сама восстанавливает прочность.
- Лазурит: прочность низкая; снижает урон от снарядов.
- Редстоун: прочность низкая; когда прочность ниже трети, игрок получает короткое ускорение.

#### Обереги рун

- Ток: ударивший по пластине враг на мгновение оглушается.
- Пламя: пластина гасит поджог на игроке.
- Узы: часть урона по пластине уходит на соседнюю пластину.
- Эхо: разрушенная пластина один раз восстанавливается на треть.
- Разлом: при разрушении пластины вокруг игрока появляется замедляющая трещина.
- Тяга: вражеские снаряды слегка отклоняются от игрока.
- Иней: ударивший в ближнем бою враг замедляется.
- Пустота: пластина игнорирует часть магического урона.

#### Особые слова брони из двух рун

- «Громоотвод» (Ток + Эхо): атакующий и ближайшие враги оглушаются дважды с интервалом.
- «Огненный круг» (Пламя + Разлом): при здоровье ниже половины вокруг игрока встаёт кольцо огня, враги его обходят.
- «Якорь» (Узы + Тяга): игрока нельзя отбросить, притянуть или сдвинуть.
- «Отражение» (Эхо + Узы): раз в несколько секунд удар целиком уходит в соседнюю пластину.
- «Ледяная стена» (Иней + Разлом): после сильного удара перед игроком на пару секунд вырастает ледяная стена.
- «Искажение» (Пустота + Тяга): вражеские снаряды огибают игрока.
- «Статический панцирь» (Ток + Иней): враги рядом с игроком замедлены и не могут бежать.
- «Закалка» (Пламя + Пустота): иммунитет к огню и лаве.
- «Укоренение» (Разлом + Тяга): если игрок стоит на месте две секунды, урон по нему сильно снижается.
- «Ледяной кокон» (Иней + Эхо): смертельный удар вмораживает игрока в кокон на три секунды неуязвимости; срабатывает редко.

#### Особые слова брони из трёх рун

- «Огненный ров» (Тяга + Пламя + Разлом): после сильного удара враги вокруг отталкиваются, вокруг игрока на несколько секунд остаётся горящий ров.
- «Сеть» (Ток + Узы + Эхо): каждый удар по игроку оглушает всех врагов в радиусе.
- «Кокон» (Пустота + Тяга + Эхо): иногда все снаряды в радиусе на несколько секунд замирают в воздухе и падают.
- «Ледяной частокол» (Иней + Ток + Разлом): вокруг игрока вырастает кольцо ледяных шипов и задерживает врагов.
- «Разделение» (Узы + Пустота + Эхо): урон по игроку делится поровну между всеми пластинами.
- «Перепад» (Пламя + Иней + Пустота): игрок не горит и не замерзает, замедления на нём вдвое короче.
- «Крепость» (Разлом + Узы + Тяга): игрок становится неподвижным бастионом — урон сильно снижен, отбросить нельзя, пока режим не отменён.
- «Аварийный рывок» (Ток + Пламя + Тяга): при критическом уроне враги вокруг отбрасываются разрядом, игрок получает рывок в сторону.
- «Метель» (Иней + Тяга + Эхо): вокруг игрока кружит вихрь и сбивает вражеские снаряды.
- «Подмена» (Пустота + Ток + Узы): при смертельном ударе игрок меняется местами с ближайшим врагом; срабатывает редко.

## Новые руды

#### Обычный мир

- Олово: частое, средняя глубина; само по себе слабое, основа дешёвых сплавов.
- Алюминий: частый, неглубоко, часто рядом с глиной; лёгкий и дешёвый, ранний металл для лёгких конструкций.
- Серебро: нечастое, горы и пещеры; магический металл, хорошо проводит ману, сильное в рунах.
- Свинец: нечастый, глубоко; тяжёлый и плотный, для защиты и экранирования.
- Платина: редкая, глубоко, иногда в одной жиле с золотом; инертная, роль — стабильность (гравировка почти не стирается, в сплавах гасит недостатки второго компонента).
- Титан: редкий, у дна, рядом с глубинным сланцем; лёгкий и прочный, основной металл поздних корпусов и рам артефактов.

#### Биом в духе Незера

- Инфернит (металл): в нём заперто вечное магическое пламя, горит не сгорая; для эффектов, которые нельзя погасить или снять обычным способом.
- Огненный опал (минерал): самоцвет с живым огнём внутри; запоминает и держит заряд магии (линзы, фокусы).

#### Биом в духе Энда

- Пустотная руда (металл): редкая, «не до конца здесь»; основа сплавов с эффектами пространства.
- Астралит (минерал): светящиеся кристаллы на нижней стороне парящих островков, почти ничего не весят; свет и скорость (линзы, проводники).

#### Узлы

- Эфирит (металл): только в области узла, выкачка и истощение его выедают; чистый магический металл, добывается только во время работы на узле.

#### Новые руды в снарядах и иглах (урон / поломка; бонус)

- Олово: низкий / высокая; застревает в цели и замедляет её.
- Алюминий: низкий / средняя; летит быстрее и дальше, почти не падает.
- Серебро: средний / средняя; двойной урон по нежити.
- Свинец: средний / низкая; придавливает цель — не может прыгать, летающих сбивает вниз.
- Платина: средний / очень низкая; почти не ломается, всегда подбирается.
- Титан: высокий / очень низкая; пробивает до трёх целей насквозь.
- Инфернит: высокий / средняя; магический огонь, не гасится водой и игнорирует огнестойкость.
- Огненный опал: средний / высокая; при попадании высвобождает заряд малым магическим взрывом.
- Пустотная руда: высокий / средняя; отбрасывает цель телепортом на несколько блоков.
- Астралит: средний / высокая; летит почти мгновенно, без падения.
- Эфирит: очень высокий / низкая; урон не снижается ни бронёй, ни сопротивлениями.

#### Новые руды в пластинах (прочность; бонус)

- Олово: низкая; дешёвая и быстро делается, без бонуса.
- Алюминий: низкая; не замедляет игрока.
- Серебро: средняя; ослабляет урон от нежити.
- Свинец: высокая; удары не накладывают яд, иссушение и слабость.
- Платина: средняя; при нуле прочности не ломается, а гаснет до починки.

- Огненный опал: средняя; копит заряд от ударов, на полном заряде даёт короткий щит.

- Астралит: низкая; игрок не получает урона от падения.
- Эфирит: высокая; восстанавливает прочность маной из накопителя.

## Фокусы

- Огранка задаёт тип фокуса, кристалл — силу, прочность и модификатор; полировка поднимает качество (множитель). Характеристики кристаллов расписываются отдельно.
- Резонанс — особое сочетание фокусов, дающее новый эффект поверх обычных; порядок не важен. У оружия — из двух-трёх фокусов одной цепочки (альтернативная цепочка может держать другой резонанс). У лёгкой брони — из фокусов разных сегментов (сетовые эффекты).
- Все эффекты — из стандартно реализуемых в Майнкрафте (оглушение, замедление, импульс, атрибуты); без невидимости, падений, скольжения и паркура.

#### Фокусы оружия (клинок — каждое попадание, молот — заряженный удар)

- Похищение: часть урона лечит игрока.
- Казнь: цель с малым здоровьем добивается.
- Разоружение: цель на время бьёт слабее.
- Страх: цель несколько секунд убегает.
- Метка: помеченная цель получает больше урона из любых источников.
- Оглушение: цель на мгновение не может двигаться и атаковать.
- Притягивание: удар подтягивает ближайшего врага к игроку.

#### Фокусы лёгкой брони

- Шлем: огнеупорность; морозостойкость; противоядие; ясность (защита от ослепления и тошноты).
- Нагрудник (ответ щита): отталкивание; ослепляющая вспышка; быстрый перезаряд щита; замедление вокруг.
- Руки (лечение): сильное разовое; длительная регенерация; лечение с очищением; лечение с подпиткой щита.
- Ноги (манёвры): длинный рывок; короткий рывок (перезарядка вдвое меньше); неуязвимость на рывке; двойной рывок.
- Мана-контур (аура): свет вокруг; замедление вражеских снарядов; ослабление атак ближайших мобов; отторжение (мелкие мобы не подходят вплотную).
- Каркас (движение): скорость; высокий прыжок; высокий шаг (подъём на блок без прыжка); ходьба по воде.

#### Резонансы оружия

- «Приговор» (Метка + Казнь): помеченная цель добивается уже с половины здоровья.
- «Пиявка» (Похищение + Разоружение): удар забирает часть силы атаки цели, игрок на время бьёт сильнее.
- «Паника» (Страх + Оглушение): оглушённая цель, очнувшись, убегает и пугает соседей.
- «Гарпун» (Притягивание + Оглушение): подтянутая цель оглушается, следующий удар по ней критический.
- «Охота» (Метка + Притягивание): притягивается всегда помеченная цель, где бы она ни была в радиусе.
- «Кара» (Казнь + Страх): добивание пускает волну страха вокруг.
- «Пир» (Похищение + Казнь): добивание сильно лечит игрока.
- «Бессилие» (Разоружение + Метка): помеченная цель несколько секунд вообще не может атаковать.
- «Бойня» (Казнь + Страх + Притягивание): после добивания подтягивается следующий враг, цепочка продолжается.
- «Хищник» (Похищение + Метка + Оглушение): поверженная помеченная цель отдаёт игроку на время свою скорость и силу.

#### Резонансы лёгкой брони

- «Феникс» (руки: разовое лечение + нагрудник: быстрый перезаряд): когда щит пробит до нуля, раз в долгое время он мгновенно восстанавливается вместе с частью здоровья.
- «Саламандра» (шлем: огнеупорность + каркас: ходьба по воде): ходьба по лаве.
- «Ледоход» (шлем: морозостойкость + ноги: длинный рывок): рывок оставляет след, замедляющий врагов.
- «Таран» (ноги: короткий рывок + нагрудник: отталкивание): рывок отбрасывает врагов на пути.
- «Скалолаз» (каркас: высокий шаг + ноги: двойной рывок): второй рывок можно направить вверх.
- «Маяк» (контур: свет + шлем: ясность): тьма и ослепление не действуют, враги вокруг подсвечены.
- «Святилище» (руки: регенерация + контур: ослабление атак): пока игрок стоит, вокруг круг, где регенерация втрое сильнее.
- «Буревестник» (каркас: прыжок + нагрудник: вспышка): приземление с высокого прыжка ослепляет врагов вокруг, урона от падения нет.
- «Неприступность» (нагрудник: замедление + контур: замедление снарядов + руки: лечение со щитом): пока щит выше половины, всё вокруг игрока замедлено.
- «Неуловимость» (ноги: неуязвимость на рывке + каркас: скорость + контур: отторжение): после рывка три секунды сильное ускорение, мобы отталкиваются от игрока.

#### Кристаллы фокусов (сила; прочность; модификатор)

- Кварц: ×0,8; высокая; без модификатора, дешёвый.
- Лазурит: ×0,9; низкая; «Экономия» — фокус тратит вдвое меньше маны.
- Аметист: ×1,0; средняя; «Рост» — прочность понемногу восстанавливается сама.
- Изумруд: ×1,1; средняя; «Удача» — шанс сработать без износа.
- Астралит: ×1,2; средняя; «Охват» — эффект задевает ещё одну ближайшую цель, у ауры больше радиус.
- Алмаз: ×1,3; очень высокая; без модификатора.
- Огненный опал: ×1,4; низкая; «Вспышка» — первое срабатывание после паузы вдвое сильнее.
- Кристалл узла: ×1,5; средняя; «Созвучие» — резонансы с этим фокусом сильнее.

## Сплавы кристаллов

- Выращиваются только в выращивателе из двух расплавов (два компонента, фиксированный рецепт). Применяются везде, где кристаллы: ячейки, фокусы, сосуды, слои снарядов, пластины, гравировка.
- Объём сосудов по возрастанию: стекло, кварц, лазурный кварц, сумеречный кварц, аметист, пламенный аметист, алмаз, звёздный алмаз, сердце узла.

#### Сумеречный кварц (кварц + аметист)

- Ячейка: мана и электричество; отдаёт тот ресурс, которого у артефакта меньше.
- Фокус: ×1,0; прочность высокая; «Гибрид» — при нехватке маны берёт электричество.
- Снаряд: урон средний, поломка высокая; бьёт одновременно обычным и магическим уроном.
- Пластина: прочность средняя; урон можно оплатить маной или электричеством вместо прочности.
- Гравировка: ×1,1; 60%; без модификатора.

#### Пьезокристалл (кварц + редстоун)

- Ячейка: электричество; подзаряжается и от ударов игрока по врагам.
- Фокус: ×1,1; прочность средняя; «Отклик» — фокусы с перезарядкой восстанавливаются на четверть быстрее.
- Снаряд: урон низкий, поломка высокая; разрушаясь, бьёт разрядом по площади.
- Пластина: прочность низкая; удары по пластине подзаряжают броню электричеством.
- Гравировка: ×1,2; 50%; «Разрядник» — каждое срабатывание слова бьёт цель малым разрядом.

#### Лазурный кварц (кварц + лазурит)

- Ячейка: мана; отдаёт заряд двумя мгновенными рывками по половине.
- Фокус: ×0,9; прочность средняя; чинится за полцены.
- Снаряд: урон низкий, поломка высокая; цель на время теряет магическую защиту.
- Пластина: прочность низкая; шанс полностью погасить вражеское заклинание.
- Гравировка: ×1,0; 55%; без модификатора, дешёвая.

#### Пламенный аметист (аметист + огненный опал)

- Ячейка: мана; опустев, ещё некоторое время понемногу отдаёт ману, прежде чем рассыпаться.
- Фокус: ×1,3; прочность средняя; прочность быстро восстанавливается сама, в бою ещё быстрее.
- Снаряд: урон средний, поломка высокая; осколки горят магическим огнём.
- Пластина: прочность средняя; если игрок горит, огонь вместо урона восстанавливает пластину.
- Гравировка: ×1,4; 65%; «Сродство с Пламенем» — руна Пламя вдвое сильнее.

#### Заря (огненный опал + астралит)

- Ячейка: электричество; отдаёт заряд мгновенно и на десять секунд ускоряет зарядку артефакта от любых источников.
- Фокус: ×1,4; прочность низкая; «Мгновенность» — эффекты фокуса без задержек.
- Снаряд: урон средний, поломка высокая; вспышка в точке попадания ослепляет всех вокруг.
- Пластина: прочность низкая; при здоровье ниже трети вспышка отбрасывает всех вокруг (с перезарядкой).
- Гравировка: ×1,5; 50%; «Вспышка» — срабатывание слова ослепляет цель.

#### Звёздный алмаз (алмаз + астралит)

- Ячейка: мана и электричество, огромная ёмкость; отдаёт всем артефактам поровну.
- Фокус: ×1,6; прочность очень высокая; «Охват» — эффект задевает ещё одну цель.
- Снаряд: урон высокий, поломка низкая; пробив цель, раскалывается за ней на осколки.
- Пластина: прочность очень высокая; не замедляет игрока.
- Гравировка: ×1,7; 90%; «Ясность» — зоны рун больше и держатся дольше (сильнее, чем у алмаза).

#### Сердце узла (кристалл узла + алмаз)

- Ячейка: мана и электричество; в зоне лагеря на узле сама восстанавливает заряд.
- Фокус: ×2,0; прочность высокая; фокус может входить сразу в два резонанса.
- Снаряд: урон очень высокий, поломка низкая; на месте попадания вырастает кристалл и несколько секунд замедляет врагов вокруг.
- Пластина: прочность максимальная; принятый урон частично восстанавливает другие пластины.
- Гравировка: ×2,0; 85%; особые слова срабатывают вдвое сильнее.

## Наконечники и структура слоёв

- Наконечник — отдельная деталь снаряда рельсы или иглы гаусса, задаёт поведение при попадании. Материал наконечника влияет только на его прочность; бонус снаряда даёт основной материал.
- Простые наконечники делаются и в литейной, и в выращивателе; сложные — только в выращивателе (растут вместе со снарядом или иглой).

#### Простые наконечники

- Бронебойный: пробивает щиты и блок противника.
- Экспансивный: раскрывается в цели, урона больше, но насквозь не пробивает.
- Ударный: не пробивает, сильно отбрасывает и на мгновение оглушает.

#### Сложные наконечники

- Взрывной: при попадании небольшой взрыв.
- Кассетный: раскрывается перед целью и выпускает веер из трёх-четырёх мини-игл.
- Кумулятивный: прожигает узким лучом, сильно больше урона бронированным целям.
- Сверлящий: застревает в цели и пару секунд продолжает вгрызаться, нанося урон.
- Прорастающий: в цели раскрываются шипы; пока они не выпали, цель замедлена и получает урон при каждом движении.
- Сковывающий: в цели мгновенно разрастается каменный нарост и на секунду обездвиживает её.

#### Структура слоёв выращенных снарядов рельсы

- Помимо материала слою можно задать особую структуру; материал остаётся и даёт свой бонус.
- Средний слой, шрапнельный: слой из шариков, при попадании разлетается конусом вперёд; бонус материала шариков срабатывает на каждой задетой цели.
- Оболочка, сбрасываемая: отделяется в полёте, снаряд летит быстрее и прямее.
- Оболочка, дробящаяся: лопается о первую цель, сердечник летит дальше.
- Сердечник, двойной: после попадания снаряд раскалывается, вторая половина летит в ближайшего врага.

## Компоненты

- Компоненты — общие детали для ступеней прокачки артефактов и постройки машин. Цепочки ведёт терминал заказа.
- Ранг компонента задаётся материалом: I — медь, бронза, кварц; II — сталь, серебро, аметист, дюраль; III — титан, электрум, алмаз и поздние сплавы.
- Вариации обработки (для любого семейства): обычный; заряженный электричеством или маной (зарядник); рунный (высекатель наносит технические рунные письмена, без выбора руны); рунный заряженный (обе обработки).
- Цена ступеней: I — обычные компоненты I ранга; II — заряженные II ранга (электричеством или маной по питанию артефакта); III — рунные III ранга. Плюс немного материала самого сегмента.
- Вершина сегмента: сердцевина из рунных заряженных компонентов обоих семейств сегмента и сгустка узла.
- Прогрессия без жёсткой привязки рангов к опорам: её мягко сдерживают сгустки узлов в части крафтов (сердцевины вершин артефактов, вершины машин базы, крафт транспорта) и доступность материалов. Ядра же — валюта Альянса, игрок выбирает, на что их тратить.
- Постройка машин (нулевой уровень) — простым крафтом из обычных материалов, без компонентов. Ступени I и выше стоят компоненты, которые выпускают машины нулевого уровня.
- Грубые компоненты (ранг 0): делаются вручную на столе артефактов, без машин, из ванильных материалов. Из них собираются базовые версии артефактов; ступени прокачки от I и выше стоят уже компоненты с машин.
- В обычном мире, ещё до базы, из грубых компонентов собираются ключ к базе, накопитель, котёл душ, бур и шахтёрский лазер.
- Материалы грубых компонентов: металлические семейства (проводка, катушка, привод, пружина, каркас, бронепанель, радиатор, сопло) — медь и железо; электрические (конденсатор, плата, эмиттер) — плюс красная пыль; контур маны — золото и лазурит; кристаллические (линза, матрица, сенсорный модуль) — стекло и аметист; колба душ — стекло и золото.

#### Семейства

- Проводка: литейная (проволока); везде, дешёвый расходный компонент.
- Катушка: литейная → высекатель → зарядник; стволы, поля, электрика.
- Конденсатор: литейная (корпус) + выращиватель (сердечник) → зарядник; аккумуляторы, запас энергии.
- Контур маны: выращиватель (жила) → высекатель; магические сегменты, щиты, фокусы.
- Линза: выращиватель → ограночная → полировка; прицелы, лучи, резонатор.
- Эмиттер: линза + катушка → зарядник; лезвие клинка, лазер, барьеры.
- Плата управления: литейная (пластина) → высекатель (дорожки); машины, терминал, управление транспорта.
- Сенсорный модуль: линза + плата; резонатор, датчики лагеря, сканер, прицел.
- Привод: литейная (шестерни, поршень) + катушка; механика, молот, бур, шагоход.
- Пружина: литейная → закалка; подвеска, отдача, ноги брони.
- Сопло: литейная (жаропрочный сплав); тяга скиммера, рывки, охлаждение.
- Радиатор: литейная (тонкие рёбра); охлаждение оружия, лазера, генератора.
- Каркас: литейная (крупные формы) → закалка; корпуса, рамы.
- Бронепанель: литейная или выращиватель (слоистая) → закалка; броня, транспорт, лагерь.
- Кристаллическая матрица: выращиватель → ограночная; подпространство (ключ, хранилище, накопитель).
- Колба душ: выращиватель (сосуд) → зарядник; котёл, накопитель.

#### Семейства по сегментам

- У сегмента два семейства (основное + второе); ступени обоих путей стоят компоненты этих семейств в разной пропорции. Заряд — тем ресурсом, на котором работает сегмент.
- Гаусс-пушка: ствол — катушка + каркас; катушки — катушка + проводка; охладитель — радиатор + сопло; аккумулятор — конденсатор + проводка; магазин — привод + пружина; прицел — линза + сенсорный модуль.
- Рельса: ствол — катушка + каркас; конденсатор — конденсатор + катушка; аккумулятор — конденсатор + проводка; казённик — привод + каркас; стабилизатор — пружина + каркас; прицел — линза + сенсорный модуль.
- Энергоклинок: эмиттер — эмиттер + катушка; привод — привод + пружина; аккумулятор — конденсатор + проводка; гнездо фокуса — контур маны + линза; мана-контур — контур маны + матрица; синхронизатор — плата + контур маны (заряд обоими ресурсами).
- Ударный молот: боёк — каркас + бронепанель; поршень — привод + катушка; аккумулятор, гнездо фокуса, мана-контур, синхронизатор — как у клинка.
- Лёгкий экзокостюм (мана): шлем — сенсорный модуль + контур маны; нагрудник — эмиттер + контур маны; руки — контур маны + привод; ноги — сопло + пружина; мана-контур — контур маны + матрица; каркас — каркас + привод.
- Тяжёлая силовая броня (электричество): шлем — бронепанель + сенсорный модуль; нагрудник — бронепанель + каркас; руки — привод + бронепанель; ноги — привод + пружина; реактор — конденсатор + радиатор; рунный узел — контур маны + плата.
- Бур: головка — привод + бронепанель; сепаратор — плата + привод; установка — каркас + пружина; двигатель — привод + катушка.
- Шахтёрский лазер: излучатель — эмиттер + радиатор; сканер — сенсорный модуль + плата; линза — линза + радиатор; аккумулятор — конденсатор + проводка.
- Шагоход: ноги — привод + пружина; корпус — каркас + бронепанель; трюм — матрица + каркас; батарея — конденсатор + проводка; полевая подзарядка — плата + катушка.
- Скиммер: левитатор — эмиттер + контур маны; двигатель — сопло + катушка; усилитель резонатора — сенсорный модуль + линза; мана-ядро — контур маны + матрица; полевая подпитка — контур маны + колба душ.
- Лагерь: установка выкачки — привод + каркас; станция подзарядки — конденсатор + контур маны; стационарный переход — матрица + эмиттер; терраформер — привод + плата; защита — эмиттер + сенсорный модуль; стоянка — каркас + привод.
- Котёл душ: горнило — колба душ + радиатор; жатва — колба душ + сенсорный модуль; сосуды — колба душ + матрица.
- Накопитель: ядро — конденсатор + матрица; раздача — контур маны + проводка.
- Резонатор: антенна — сенсорный модуль + катушка; анализ — сенсорный модуль + плата.
- Хранилище: карман — матрица + каркас; связь — матрица + плата.
- База: генератор — конденсатор + радиатор; простор — матрица + каркас; ключ — матрица + эмиттер.
- Машины базы: переработка руды — привод + каркас; плавильня — радиатор + каркас; сплавщик — привод + контур маны; литейная — каркас + радиатор; выращиватель — матрица + контур маны; зарядник — конденсатор + контур маны; ограночная — линза + привод; высекатель рун — эмиттер + плата; шредер — привод + бронепанель; терминал заказа — плата + сенсорный модуль.
