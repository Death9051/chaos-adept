# Graphify: граф кода репозитория

Репозиторий `Death9051/chaos-adept` проиндексирован в Graphify. Передавай `repository_id: "Death9051/chaos-adept"` во все вызовы.

## Какой инструмент когда

| Нужно | Инструмент |
|---|---|
| где определён класс, метод, поле | `graphify_find` (фрагмент имени, не вопрос), потом `graphify_node` — прочитать |
| как устроена часть кода | `query_graph` (вопрос словами) |
| кто вызывает метод | `graphify_callers` |
| что заденет изменение | `graphify_impact` с `include_risk=true` |
| какие геймтесты проверяют класс или файл | `graphify_tests_for` |
| зависимости файла | `graphify_file_neighbors`, `graphify_imports_exports` |
| какие файлы читать по задаче | `graphify_rank_files` |

## Порядок работы

1. Перед правкой: `graphify_impact` по тому, что меняешь, и `graphify_tests_for` — чтобы знать, какие геймтесты обновить или добавить.
2. Перед изменением API событий ядра (`ru.adept.core.api`): `graphify_callers` — кто слушает событие в «Сюжете». API меняет только «Ядро» (CLAUDE.md).
3. Ответы Graphify описывают код на коммите, по которому построен индекс (поле `freshness`). Если ветка ушла вперёд или файл менялся в этой сессии, проверь по самим файлам.

## Ограничения

- Бесплатный план: из документов индексируется только `README.md`, поэтому `docs/` в графе нет — документы читай напрямую.
- Индекс строится по `main` после пуша; свежая ветка в графе не видна.
- Если инструменты Graphify недоступны в сессии (коннектор не подключён), работай обычным поиском (Grep, Glob).
