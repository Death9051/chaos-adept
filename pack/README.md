# Состав сборки

Сторонние моды и шейдерпаки, которые входят в сборку. Зона чата «Сборка».

| Файл | Что это |
|---|---|
| `mods.txt` | список проектов Modrinth (машинная копия «Списка модов»), правится руками |
| `modrinth.lock.json` | точные версии, файлы и хеши, включая подтянутые зависимости; генерируется |
| `config/` | конфиги сторонних модов: кладутся в папку `config` игры; файл можно писать частично, недостающие ключи мод допишет сам |
| `datapack/` | правки сторонних модов данными (например, убрать мобов из спавна); едет в jar ядра, файлы с условием `neoforge:mod_loaded` |

## Как обновить состав

1. Поправить `mods.txt` (добавить строку, закрепить версию).
2. Открыть pull request. CI увидит, что lock устарел, разрешит версии заново и положит новый lock
   и отчёт в ветку `ci-logs`: `runs/<прогон>/logs-fullpack/ci-out/modrinth.lock.json` и `pack-report.md`
   (версии, лицензии, стороны, кто кого подтянул).
3. Забрать новый lock в `pack/` тем же pull request. С этого момента прогоны берут ровно эти файлы.

Локально (если есть доступ к Modrinth): `python3 .github/scripts/pack.py resolve`.

## Как используется

- CI, задание **fullpack**: `pack.py fetch` кладёт файлы в папки запусков `story/run/fullpack-*`
  (сверка sha512) и копирует `pack/config`, затем сервер геймтестов и клиент со сценами работают со всей сборкой.
- Моды с флагом `dev` уже подключены в обычных запусках Gradle и в папку fullpack не кладутся.
- Шейдерпаки лежат в `shaderpacks/` и по умолчанию выключены; включает игрок в настройках Iris.
  Пробный прогон CI включает MakeUp — Ultra Fast.
- Поля lock совпадают с `modrinth.index.json`, из него собирается `.mrpack` для публикации.
